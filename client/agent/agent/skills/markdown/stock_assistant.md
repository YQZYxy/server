## 股票查询技能

当用户询问股票相关内容时, 遵循以下规则.

### 0. 优先使用股票工具

优先使用以下专用工具, 比网页搜索更快更准确:

- **`stock_quote`** — 实时行情查询(股价、涨跌幅、成交量、换手率、市盈率、市值等)
- **`stock_history`** — 历史K线查询(日K/周K/月K, 支持前复权/后复权/不复权)

仅当以上工具无法满足需求时(如新闻、财务分析、公司公告等), 才使用 `web_search` 工具进行网页搜索.

### 一、识别股票

- **用户说公司名** → 补全股票代码再搜索
  - A股: 沪市 `sh{代码}`, 深市 `sz{代码}`, 北交 `bj{代码}`
  - 港股: `{代码}.HK`
  - 美股: 直接用字母代码
- **用户说模糊名** → 先确认再搜索, 如 "茅台" → "贵州茅台 600519"
- **用户说代码** → 补全市场前缀, 如 "600410" → "华胜天成 600410 sh600410"
- **同名不同公司** → 加上股票代码或行业区分, 如 "华胜"(汽修) vs "华胜天成 600410"(IT)

### 三、结果筛选优先级

1. **行情类**: 东方财富 > 同花顺 > 新浪财经 > 证券之星
2. **财务类**: 巨潮资讯(cninfo.com.cn) > 东方财富 > 证券时报
3. **公告类**: 巨潮资讯(官方披露) > 公司官网
4. **新闻类**: 财联社 > 华尔街见闻 > 证券时报 > 上海证券报
5. **研报类**: 东方财富研报中心 > 同花顺研报
6. **港股类**: 阿斯达克(aastocks.com) > 东方财富国际
7. **美股类**: Yahoo Finance > MarketWatch > 东方财富美股

### 五、重要规则

- **实时股价动态变化**, 搜索结果可能不包含精确的实时数字, 此时引导用户访问专业平台
- **A股交易时间**: 周一至周五 9:30-11:30 / 13:00-15:00 (节假日休市)
- **不提供投资建议**, 仅展示客观数据, 加 disclaimer: "以上信息仅供参考, 不构成投资建议"
- **多市场注意**: 港股有交易日历差异, 美股有盘前盘后交易
- **如果搜索结果不理想**, 换一组关键词重试, 或指定更权威的财经来源
- **财务数据注意日期**, 注明是哪个报告期(如2026Q1、2025年报)
