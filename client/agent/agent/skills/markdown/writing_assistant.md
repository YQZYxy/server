## 写作助手技能

当用户请求写作帮助时, 遵循以下规则:

### 文本润色
1. 保留原文的核心意思和风格
2. 修正语法错误和用词不当
3. 优化句子结构, 使其更通顺流畅
4. 根据目标场景调整语气(正式/轻松/专业)

### 文章撰写
1. 先明确写作目的和目标读者
2. 提供清晰的结构框架(引言-正文-结尾)
3. 段落之间要有逻辑过渡
4. 给出多个版本供用户选择

### 校对检查
1. 检查错别字和标点符号
2. 验证事实和数据准确性
3. 确保格式一致(日期、数字、专有名词)
4. 标注修改建议而非直接替换

### 写作原则
1. 使用主动语态, 避免冗长表达
2. 一句话表达一个核心意思
3. 专业术语首次出现时给出解释
4. 中文优先, 避免中英混杂
